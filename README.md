# Employee Satisfaction and Workplace Experience Analysis
## Project Overview
This project focuses on analyzing employee reviews, job details, and employee satisfaction data to identify the major factors influencing employee satisfaction and overall workplace experience.

The analysis explores areas such as:

- Employee Satisfaction
- Work-Life Balance
- Skill Development
- Salary and Benefits
- Job Security
- Career Growth
- Overall Employee Rating
- Job Type
- Department
- Location

## Dashboard Pages
### Employee Reviews
Provides a high-level operational overview of employees reviews.

#### Key Insights:
- Overall Rating
- Worklife balance
- Career growth
- Total reviews
### Review Analysis
Focuses on improving worklife.

#### Key Insights
- Job type and skill development
- Job security
